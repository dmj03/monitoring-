# UC3 Monitoring Alert Triage POC — pinned dependencies.
#
# Pinned to the versions this project was built and validated against, not to
# the latest available. The goal is reproducing the current verified state.
#
# Determined by AST-scanning every .py file for third-party imports, then
# reading the installed version of each. Nothing here is speculative:
#
#   fastapi   backend/api/{main,routes}.py        — the API layer
#   pydantic  backend/api/schemas.py              — request/response models
#   PyYAML    12 files (KB loading, every engine and validator)
#   httpx     required by fastapi.testclient, which backend/tests/api uses
#   uvicorn   ASGI server; the process that actually serves backend.api:app
#   openai         backend/ai/analyst.py              — the AI analyst summary, the
#                                                       only model call in the project
#   python-dotenv  backend/api/main.py                — loads OPENAI_* from .env
#
# starlette, pydantic-core, anyio, click and h11 are transitive dependencies of
# fastapi, pydantic and uvicorn. They are deliberately not pinned here: pinning a transitive
# dependency without a lockfile risks conflicting with its parent's own range.
#
# The core backend — DataStore, InvestigationEngine, ClusterEngine — needs only
# PyYAML. fastapi, pydantic and httpx are needed solely for the API layer and
# its tests, which is why the backend remains usable without them.
